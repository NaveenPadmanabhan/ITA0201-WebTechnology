WEB TECHNOLOGY — UNIT IV
XPATH BROWSER

UPDATED VERSION

This version does NOT display all courses when the page opens.
The user must manually enter/run an XPath expression.

Files:
- index.html — interactive Retro/Vintage XPath browser
- courses.xml — assessment XML dataset
- transform.xsl — XSLT solution for Question 3
- xpath_answers.txt — Question 2 XPath expressions
- interpretation.txt — Questions 1 and 4
- submission_notes.txt — verification notes
- README.txt — this file

How to use:
1. Open index.html in a modern browser.
2. Enter an XPath expression.
3. Click RUN QUERY.
4. Only matching nodes are displayed.

The example buttons only LOAD an XPath into the input box; they do not display results until RUN QUERY is pressed.
